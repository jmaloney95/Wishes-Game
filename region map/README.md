# Custom Region Map — Implementation Guide

Everything here is for a **pokeemerald (decomp)** hack. Files are organized to
mirror your repo structure so you can mostly copy-paste into place.

```
graphics/pokenav/region_map.png          <- your finished 224x160 16-color art
graphics/pokenav/region_map.pal          <- the 16-color JASC palette
src/data/region_map/region_map_entries.h <- cursor rectangles + names
src/data/region_map/region_map_section_names.h <- the gText_* name strings
include/constants/region_map_sections.h  <- MAPSEC_* IDs
region_map_PREVIEW.png                    <- 6x preview (not used in-game)
```

---

## Why there is no `region_map.bin` / `region_map_map.bin` in this package

The region map background is an **affine** background, which hard-caps the
tileset at **256 unique tiles**. Your art deduplicates to **233 tiles**, so it
fits — but the actual `.bin` files (a deduplicated tileset image + a padded
64x64 tilemap with a specific palette-index and color-0 convention) are
generated by **Tilemap Studio**, the supported tool for this. Hand-rolling
those binaries is fragile and easy to get wrong; Tilemap Studio does it
correctly in about two minutes. Steps below.

---

## Step 1 — Generate the tileset + tilemap in Tilemap Studio

1. Open **Tilemap Studio** (v4.0+).
2. `Tools > Image to Tiles`.
3. Input image: `region_map.png` (the 224x160 file in this package).
4. Settings:
   - **Format:** GBA (4bpp)
   - **Palette format:** first export as **PaintShop Pro (JASC-PAL)** to get a
     `.pal`, then export again as **Indexed in tileset image** for a colored
     tileset PNG. (You can also just use the `region_map.pal` included here.)
   - **Start at palette index `$70`** (0x70) — this matches what the region map
     loader expects in stock pokeemerald.
   - Make sure **color 0 is a unique color** the map never uses, because color
     0 can be treated as transparent in-game. (Hoenn uses pure black #000000 as
     color 0.) If needed, shift your palette so index 0 is an unused color.
5. This produces `region_map.png` (tileset) + a `.bin` tilemap.

## Step 2 — Pad/shift the tilemap to 64x64

The map is 28x20 tiles but the hardware background is 64x64. In Tilemap Studio:

1. Open the generated tilemap.
2. `Edit > Resize` to **64 x 64**.
3. Use **Shift Tilemap (Ctrl+M)** if you authored extra edge rows; otherwise
   just place your 28x20 map in the top-left and leave the rest as the ocean/
   blank tile.
4. Save as `graphics/pokenav/region_map_map.bin` (and the secondary
   `graphics/interface/region_map.bin` if your project layout uses it — newer
   pokeemerald keeps these under `graphics/pokenav/region_map/`).

> Tip: if your project is recent, the region map graphics live in
> `graphics/pokenav/region_map/`. Match whatever your existing
> `region_map.png` path is.

## Step 3 — Drop in the palette + tileset

- Replace your project's region map `.pal` with `region_map.pal` here, OR use
  the one Tilemap Studio generated (they're equivalent).
- Replace the region map tileset PNG with the one from Step 1.

## Step 4 — Wire up the map sections (the C side — DONE for you)

1. **`include/constants/region_map_sections.h`** — merge in the `MAPSEC_*`
   defines from the included file. Keep `MAPSEC_NONE` as the final/highest
   value and update the count.
2. **`src/data/region_map/region_map_section_names.h`** — add the `gText_*`
   strings.
3. **`src/data/region_map/region_map_entries.h`** — add the
   `sRegionMapEntries[]` rectangles. These define where the cursor lands and
   what name shows.

## Step 5 — Link each overworld map to its section

In **Porymap**, open each map's **Header** tab and set the **Location** field
to the matching `MAPSEC_*` (e.g. your starting town map → `MAPSEC_NORTHWOOD_TOWN`).
That's the only Porymap step — the region image itself is NOT painted in
Porymap's map editor.

## Step 6 — Fly / heal locations (optional, do when towns are ready)

For each town the player can Fly to, add a heal-location entry pointing at the
MAPSEC. In recent pokeemerald this is data-driven in
`src/data/heal_locations.h` (older versions: `sMapHealLocations` /
`sFlyDestinations`). Set the warp's map group/num and its MAPSEC.

## Step 7 — Build & check in-game

```
make -j$(nproc)
```

Open the PokeNav region map in-game. Move the cursor over each area and confirm
the right name appears. Adjust rectangles in
`region_map_entries.h` (or visually in Porymap's Region Map Editor, Ctrl+M) if
any box is off.
